Instructions & data management

Before the field day

Open this HTTPS website while online, add it to your home screen, then open that new home-screen icon while still online. Check for “Offline ready” above. Test it in airplane mode before field work.

During flight

Use one phone per observer. Keep phone clocks set to automatic date and time. Start each flight at the same pilot cue, then tap green when you can see the drone and red when you cannot. Repeat as often as visibility changes. An accidental tap can be marked void using Undo.

After flight

End the flight log; repeat for the next drone. Use Share / Save CSV to save a file to Files or share it, or use Download CSV. Export a backup before clearing anything. The CSV includes UTC, Unix milliseconds, elapsed milliseconds, flight/pass numbers, and any voided taps.

Important

This is a research recording aid, not a flight safety or airspace authorization system. Keep the appropriate pilot/VO procedures in place. Do not use private/incognito browsing; do not clear this site's data or uninstall the home-screen app before exporting.
